# 📌 Avisos para clientes
Bem-vindo à área de clientes! Aqui a equipe publica avisos que valem só para quem comprou.

**Sua conta**
• O login é **único** e fica **vinculado ao seu PC** no primeiro acesso. Entre pela primeira vez no computador em que vai usar o app.
• Reinstalar o Windows ou trocar o processador não desfaz o vínculo.
• Trocou de PC ou de placa-mãe? Pegue o código em **Configurações › Perfil › Este computador** e abra um atendimento em <#1575535429220835390>.
• Só existe uma sessão por conta: entrar de novo encerra a anterior.
• Compartilhar ou revender o login leva ao bloqueio da conta.
